# @tidy-ts/dataframe-darwin-arm64

Native binary for [@tidy-ts/dataframe](https://www.npmjs.com/package/@tidy-ts/dataframe) on macOS ARM64 (Apple Silicon).

This package is automatically installed as an optional dependency — you should not need to install it directly.

See the main package for documentation: https://github.com/jtmenchaca/tidy-ts
