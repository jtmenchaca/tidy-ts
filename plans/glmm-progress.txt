## Background

This implementation adds GLMM support to tidy-ts, targeting clinical/epidemiological use cases
where hierarchical data structures require random effects modeling (e.g., patients nested in
providers nested in clinics).

### Key Design Decisions

1. **Laplace Approximation** - Matches glmmTMB default, provides good balance of speed/accuracy
2. **Log-Cholesky Parameterization** - Unconstrained optimization for variance components
3. **Sparse Z Matrices** - Block-diagonal for nested, COO for crossed random effects
4. **Reuse GLM IRLS** - Existing infrastructure handles fixed effects estimation

### Reusable Components (from existing codebase)

- `glm_fit_core.rs` - IRLS algorithm (800+ lines)
- `qr_decomposition.rs` - Weighted least squares solver (420 lines)
- `family/*` - Gaussian, Binomial, Poisson, Gamma, InverseGaussian
- `gee/types.rs` - ClusterInfo structure
- `gee/correlation/*` - Exchangeable, AR1, Unstructured patterns

### New Components Required

1. **Random Effects Module** (`random_effects.rs`)
   - Z matrix construction (sparse)
   - Random effect likelihood
   - BLUP extraction

2. **Variance Components Module** (`variance_components.rs`)
   - Log-Cholesky parameterization
   - Theta <-> Sigma transformations
   - Jacobian for REML

3. **Laplace Module** (`laplace.rs`)
   - Joint log-likelihood
   - Mode finding (Newton)
   - Hessian computation
   - Marginal likelihood approximation

4. **Fitting Module** (`fitting.rs`)
   - Profile likelihood
   - Outer optimization (BFGS/Newton)
   - Convergence monitoring

5. **Families Extension**
   - Nbinom1, Nbinom2 families
   - Dispersion parameter handling

### Performance Targets

| Scenario | Target |
|----------|--------|
| 5000 obs, 50 groups, 1 RE | < 1 second |
| 10000 obs, 100 groups, 2 RE | < 5 seconds |
| Coefficient accuracy | Within 1e-4 of glmmTMB |
| SE accuracy | Within 1e-3 of glmmTMB |

**Key Types Implemented:**

1. **RandomEffect** - Specifies a random effect term
   - `grouping_var`: Variable used for grouping (e.g., "patient")
   - `terms`: Random effect terms (e.g., ["1", "x"] for intercept + slope)
   - `n_groups`, `group_sizes`, `group_ids`, `group_indices`: Group metadata
   - `covariance`: CovarianceType (Independent, Unstructured, CompoundSymmetry)
   - Helper methods: `n_terms()`, `total_coefficients()`, `n_variance_params()`

2. **GlmmControl** - Control parameters for fitting
   - `max_iter_outer`, `max_iter_inner`: Iteration limits
   - `tol_outer`, `tol_inner`: Convergence tolerances
   - `verbose`, `reml`, `optimizer`: Fitting options
   - `start_theta`, `start_beta`: Optional starting values
   - Builder pattern methods: `with_ml()`, `with_max_iter()`, etc.

3. **GlmmResult** - Complete fit result (extends GlmResult)
   - `glm_result`: Reuses all GLM fixed effects infrastructure
   - `random_effects`: Vec<RandomEffect> specifications
   - `variance_components`: Vec<VarianceComponent> estimates
   - `blups`: Vec<RandomEffectEstimates> (BLUPs with optional SE)
   - `theta`, `theta_se`: Variance component parameterization
   - `log_likelihood`, `aic`, `bic`, `reml_criterion`: Fit statistics
   - `converged`, `convergence_message`, `outer_iterations`: Convergence info

4. **VarianceComponent** - Variance estimates for one random effect
   - `vcov`: Variance-covariance matrix
   - `std_dev`: Standard deviations
   - `correlation`: Optional correlation matrix
   - `std_errors`: Optional SE of variance parameters

5. **RandomEffectEstimates** - BLUPs for one grouping factor
   - `estimates`: n_groups x n_terms matrix
   - `std_errors`: Optional conditional SE
   - `conditional_vcov`: Optional full conditional variance

6. **CovarianceType** - Enum for covariance structures
7. **GlmmOptions** - Options for BLUP computation, weights, etc.
8. **GlmmFitSummary** - Summary statistics
