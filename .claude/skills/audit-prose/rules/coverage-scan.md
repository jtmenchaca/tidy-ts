# Coverage scan

Before any phrase-level work, check that every load-bearing claim is reachable from the places a reader would look for it.

## What "coverage" means

Documents have entry points — Abstract, Conclusion, cover letter, executive summary, table of contents, section headings. A reader who lands at any of these should not miss a contribution the body of the document makes.

If the body of the document has two contributions (e.g., a primary study and an external validation), each entry point should mention both. A reader who reads only the Abstract should not infer the document is about only one contribution.

## How to run the scan

List the document's contributions in one column and its summary-level sections in another. For each contribution, ask which sections mention it. A blank cell where a reader would look is a finding.

Example for a manuscript with two contributions:

|                       | Abstract M&M | Abstract Results | Conclusion | Cover letter | Tweet |
|---                    |---           |---               |---         |---           |---    |
| Contribution A        | ✓            | ✓                | ✓          | ✓            | ✓     |
| Contribution B        | ✓            | ✓                | ✓          | ✓            | ✓     |

A row with an empty cell is a finding.

The CONTEXT.md (if one exists) names the contributions explicitly. Use it.

## What to do with a finding

A coverage gap is a structural problem, not a phrase problem. Propose adding the missing content to the summary-level section before any phrase pass begins. Editing prose around a coverage gap is wasted work.

Example: if Abstract Results does not mention Contribution B, propose one sentence to add that names B's headline number. Wait for approval. Apply. Then continue.

## Headings and openers

Check that headings match what follows them. If a paragraph beneath a heading was rewritten during the audit to remove jargon, the heading may need to be rewritten too.

Check that section openers (the first sentence of each major section) preview what is coming. A section that opens with a topic sentence the reader can use is easier to navigate than one that drops the reader mid-claim.

## Why this comes before phrase work

A phrase pass cannot detect coverage gaps. The pass walks the document from top to bottom and asks "is this sentence clean"; it does not ask "should this sentence exist at all?" Coverage gaps require asking the second question. So coverage comes first.
